# Power BI Dashboard Guide

Connect Power BI to MySQL or import `data/processed_orders.csv`.

## Page 1 — Executive Overview
KPIs: Total Sales, Total Orders, Total Profit, Customers, Average Order Value, Profit Margin.
Charts: Monthly Sales, Monthly Profit, Sales by Category, Sales by Region.

## Page 2 — Product Analysis
Top 10 Products by Sales, Top Products by Units Sold, Profit by Category, Discount vs Profit.

## Page 3 — Customer Analysis
Top Customers by Spend, Orders per Customer, Average Order Value, optional RFM segmentation.

Recommended slicers: Date, Category, Region, Payment Method, Order Status.

Never invent dashboard insights; use values from the actual dataset.
