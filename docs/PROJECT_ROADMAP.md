# Project Roadmap

1. Data: select dataset, inspect quality, clean with Python/Pandas.
2. SQL: create MySQL schema and 15–20 analytical queries.
3. BI: create 3 Power BI pages.
4. Backend: create Express REST APIs.
5. Frontend: create React dashboard and charts.
6. Enhancements: JWT auth, filters, CSV upload, RFM segmentation, export and deployment.

Interview topics: database schema, joins, aggregations, REST APIs, KPI definitions, indexing, data cleaning, profit margin and why Power BI is used alongside a custom dashboard.
